# Security Policy

## Supported Versions

See our website for versions of DigiByte Core that are currently supported with
security updates: https://digibyte.org/en/lifecycle/#schedule

## Reporting a Vulnerability

Report security issues privately by emailing security@digibyte.io or using
[GitHub's private vulnerability reporting](https://github.com/DigiByte-Core/digibyte/security/advisories/new).
These channels are for security reports, not general support.

Include the affected version, the expected behavior, what happened, and steps
to reproduce the problem. Do not put sensitive details in a public issue.
